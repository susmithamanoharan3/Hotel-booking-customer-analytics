# Hotel Booking & Customer Behaviour Analytics

## Project Overview
This project analyses hotel booking data to understand booking patterns, customer behaviour, cancellation trends and hotel performance using Python.

## Dataset
Hotel Booking Demand Dataset – Kaggle

Dataset Link: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Steps
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Data Type Conversion
- Outlier Detection
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Data Visualization

## Feature Engineering
- Arrival Date
- Total Nights
- Total Guests
- Arrival Month Number

## Visualizations
- Pie Chart
- Donut Chart
- Bar Plot
- Box Plot
- Joint Plot
- Correlation Heatmap

## Key Findings
- Approximately 27.52% of bookings were canceled.
- Transient customers had the highest cancellation rate among customer types.
- TA/TO was the most common distribution channel.
- Corporate bookings had a lower cancellation rate compared with other major distribution channels.

## Conclusion
This project helped explore hotel booking patterns, customer behaviour and cancellation trends. Python-based data cleaning, analysis and visualization were used to extract meaningful insights from the dataset.
